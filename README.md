# Kite Interface Refresh

Redesign the frontend UI of my website https://www.kiteinternationals.com/ to match the clean, modern, and professional look of https://www.idp.com/india/.

IMPORTANT INSTRUCTIONS:

1. DO NOT change any backend logic, database, API integrations, or functionality.

2. DO NOT remove, modify, or replace any existing services, features, or content.

3. KEEP all service pages exactly the same in terms of content and structure.

4. ONLY improve the UI/UX, layout, styling, spacing, typography, and responsiveness.

DESIGN REQUIREMENTS:

• Use a clean white background theme similar to IDP.

• Follow a professional, minimal, corporate design style.

• Improve spacing, alignment, and visual hierarchy.

• Use modern fonts (like Inter, Poppins, or similar).

• Add soft shadows, rounded corners, and subtle hover effects.

• Improve button styles (clear CTAs like "Apply Now", "Explore", etc.).

• Use a consistent color palette (primary + secondary + neutral tones).

• Ensure high readability and accessibility.

LAYOUT IMPROVEMENTS:

• Redesign the homepage with:

  - Clean hero section (headline + CTA + image)

  - Structured sections for services

  - Clear navigation bar (sticky, modern)

  - Professional footer

• Improve all pages:

  - Better card-based layouts

  - Consistent padding and margins

  - Grid-based alignment

  - Proper section separation

• Navigation:

  - Modern top navbar

  - Dropdowns if needed

  - Highlight active page

RESPONSIVENESS:

• Fully responsive for:

  - Mobile

  - Tablet

  - Laptop

  - Large screens

• Ensure mobile-first design approach

COMPONENT IMPROVEMENTS:

• Cards for services

• Clean forms (better input fields, spacing)

• Improved dropdowns and selectors

• Modern icons (use Lucide or similar)

ANIMATIONS:

• Add subtle animations:

  - Hover effects

  - Smooth transitions

  - Fade-in sections on scroll

CONSISTENCY:

• Maintain consistent design across all pages

• Use reusable components

• Keep branding aligned with Kite International

OUTPUT EXPECTATION:

• Provide updated frontend code (React / Next.js + Tailwind CSS preferred)

• Maintain existing project structure

• Do not break any existing functionality

GOAL:

Make the website look like a premium, professional platform similar to IDP while keeping all existing services and functionality intact.
